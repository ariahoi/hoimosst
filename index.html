MOSST

Модель малой двигательной установки с аэроспайком, которая выбирает схему сама

Она подбирает пару топлив, материал, подачу и вариант плуга, считает размеры и строит деталь для печати. При заданном полном импульсе ищет наименьшую стартовую массу. Габарит, ресурс, тепло в борт, пиковая мощность и минимальный импульс включения — жёсткие ограничения, а не слагаемые взвешенной суммы.

Контур — приближённый метод Анджелино, те же соотношения, что в Cem.Physics. Сравнение с колоколом идеализированное: аэроспайк расширяется до давления среды, колокол перерасширен и отрывается по критерию Саммерфилда, pотр ≈ 0,4·pa. В вакууме граница струи разворачивается далеко наружу, поэтому для аппарата важен тепловой поток в борт.

Девять осей выбора дают 373 248 дискретных сочетаний, и у каждого есть ещё непрерывные размеры. Перебрать всё нельзя, поэтому модель отсеивает лестницей: каждая ступень дороже и точнее предыдущей и видит только тех, кого та пропустила.

Граница, а не оценка

Дешёвая ступень обязана давать оптимистичную границу: настоящая конструкция не может оказаться легче её. Вариант уходит, только если даже его граница хуже уже найденной конструкции. Если вместо границы взять оценку, можно выбросить лучший вариант. Двигайте рекорд и переключайте режим.

Схема принципа: двенадцать условных вариантов, массы в условных единицах. Рекорд не бывает легче лучшей конструкции, потому что он сам конструкция.

m₀ ≥ max( minP { IΣ / cmax(P) + (aб + aг)·P } ; IΣ / cmax )

Давление в камере P — переменная, граница берёт минимум по нему. aб, aг — цена давления баков и баллона наддува по теореме о вириале, без зависимости от формы оболочки.

Модель печатается слоями

Каждый слой — принятый инкремент: сборка без предупреждений, все тесты зелёные, числа совпали с прототипом, ревью без блокеров. Штриховка каждого слоя повёрнута на 67° к предыдущему, как векторы сканирования в L-PBF. Сверху — порошок, который ещё не сплавлен.
